# 宠物之家管理系统 - 功能补充实现计划

## 概述
根据 `功能.docx` 需求文档，在现有 Spring Boot + Vue 3 项目基础上，补充实现以下缺失功能模块：
- 宠物信息管理 (Animal)
- 宠物领养管理 (Adopt)
- 宠物房间管理 (Room)
- 宠物寄养管理 (Foster)
- 流浪动物上报管理 (Submit)
- 宠物用品管理 (Goods)
- 用户余额充值功能
- 对应的前后端页面

**现有项目保留不变**：b_user, b_thing, b_order 等已有表和功能继续保留。新增表不使用 `b_` 前缀（按用户要求）。

---

## 第一步：数据库建表 (schema.sql 追加)

在 `pet/src/main/resources/schema.sql` 末尾追加 6 张新表：

```sql
-- animal 表
CREATE TABLE `animal` (
  `pid` INT NOT NULL AUTO_INCREMENT,
  `photo` VARCHAR(255), `nickname` VARCHAR(255), `gender` VARCHAR(255),
  `years` INT, `breed` VARCHAR(255), `condition` VARCHAR(255),
  `introduction` VARCHAR(255), PRIMARY KEY (`pid`)
);

-- adopt 表
CREATE TABLE `adopt` (
  `record_id` INT NOT NULL AUTO_INCREMENT,
  `owner_uid` INT, `pet_uid` INT, `adopt_date` VARCHAR(255),
  `state` VARCHAR(255), PRIMARY KEY (`record_id`)
);

-- room 表
CREATE TABLE `room` (
  `id` INT NOT NULL AUTO_INCREMENT,
  `name` VARCHAR(255), `status` VARCHAR(255),
  `animal` VARCHAR(255), PRIMARY KEY (`id`)
);

-- foster 表
CREATE TABLE `foster` (
  `order_id` INT NOT NULL AUTO_INCREMENT,
  `client_uid` INT, `pet_name` VARCHAR(255), `start_date` VARCHAR(255),
  `duration` INT, `progress` VARCHAR(255), `cage_no` INT,
  PRIMARY KEY (`order_id`)
);

-- submit 表
CREATE TABLE `submit` (
  `id` INT NOT NULL AUTO_INCREMENT,
  `name` VARCHAR(255), `img` VARCHAR(255), `time` VARCHAR(255),
  `status` VARCHAR(255), PRIMARY KEY (`id`)
);

-- goods 表
CREATE TABLE `goods` (
  `id` INT NOT NULL AUTO_INCREMENT,
  `name` VARCHAR(255), `img` VARCHAR(255),
  `price` INT, `num` INT, PRIMARY KEY (`id`)
);
```

同时修改 `b_user` 表，添加 `balance` 字段（INT，默认0）。

## 第二步：后端 Java 代码

### 2.1 新增实体类 (entity/)
为每张新表创建实体类，使用 `@TableName` 注解映射到无前缀表名。

| 文件 | 表 | 主键字段 |
|------|------|---------|
| `entity/Animal.java` | animal | pid |
| `entity/Adopt.java` | adopt | record_id |
| `entity/Room.java` | room | id |
| `entity/Foster.java` | foster | order_id |
| `entity/Submit.java` | submit | id |
| `entity/Goods.java` | goods | id |

### 2.2 修改 User 实体
在 `entity/User.java` 中添加 `balance` 字段（Integer 类型）。
> 注意：User.java 可能是加密文件，如果是则创建新的 UserBalance 相关逻辑或通过其他方式处理。

### 2.3 新增 Mapper 接口 (mapper/)

| 文件 | 继承 |
|------|------|
| `mapper/AnimalMapper.java` | BaseMapper<Animal> |
| `mapper/AdoptMapper.java` | BaseMapper<Adopt> |
| `mapper/RoomMapper.java` | BaseMapper<Room> |
| `mapper/FosterMapper.java` | BaseMapper<Foster> |
| `mapper/SubmitMapper.java` | BaseMapper<Submit> |
| `mapper/GoodsMapper.java` | BaseMapper<Goods> |

每个 Mapper 需要自定义方法的，额外创建对应 XML 文件：
- `mapper/AdoptMapper.xml` — 查询领养列表含用户和宠物信息（JOIN 查询）
- `mapper/FosterMapper.xml` — 查询寄养列表含用户信息
- `mapper/SubmitMapper.xml` — 查询上报列表

### 2.4 新增 Service 接口和实现

| Service 接口 | 实现类 | 核心方法 |
|-------------|--------|---------|
| `AnimalService` | `AnimalServiceImpl` | selectAll, add, updateById, deleteById, selectById |
| `AdoptService` | `AdoptServiceImpl` | selectAll, add, updateById, selectById |
| `RoomService` | `RoomServiceImpl` | selectAll, add, updateById, deleteById |
| `FosterService` | `FosterServiceImpl` | selectAll, add, updateById |
| `SubmitService` | `SubmitServiceImpl` | selectAll, add, updateById |
| `GoodsService` | `GoodsServiceImpl` | selectAll, add, updateById, deleteById, selectById |

所有 Service 继承 `ServiceImpl<XxxMapper, Xxx>` 并使用 `@Service` 注解。

### 2.5 新增 Controller

| Controller | 路径前缀 | 功能 |
|-----------|---------|------|
| `AnimalController` | `/animal` | list, create, update, delete, detail |
| `AdoptController` | `/adopt` | list, create, update, detail |
| `RoomController` | `/room` | list, create, update, delete |
| `FosterController` | `/foster` | list, create, update |
| `SubmitController` | `/submit` | list, create, update |
| `GoodsController` | `/goods` | list, create, update, delete, detail |

所有 Controller 使用 `@RestController` + `@RequestMapping`，返回 `APIResponse`。
遵循现有项目模式：注入 Service，调用 MyBatis-Plus 的 CRUD 方法。

### 2.6 修改现有 Controller
- **UserController**: 添加 `/user/recharge` 接口（余额充值），添加 `/user/getBalance` 查询余额
- **OrderController**: 添加用品订单创建逻辑（如果需要区分宠物订单和用品订单）
